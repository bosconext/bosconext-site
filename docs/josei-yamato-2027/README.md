# 2027年度 ヤマト福祉財団「障がい者福祉助成金」 申請書類（BOSCO NEXT）

募集要項の「２）障がい者福祉助成金を申請する団体・事業所」①にあたる
**企画書・スケジュール・費用積算表**の3点です（いずれも書式自由・A4）。

## ファイル一覧

| ファイル | 内容 | 形式 |
|---|---|---|
| `01_企画書.docx` | 企画書（A4縦・5ページ） | Word。そのまま加筆・修正できます |
| `02_スケジュール.xlsx` | 別紙1 スケジュール（A4横・1ページ／ガントチャート） | Excel |
| `03_費用積算表.xlsx` | 別紙2 費用積算表（A4縦・1ページ／数式入り） | Excel |

提出時はPDFに変換してください（Word/Excelとも「名前を付けて保存 → PDF」）。

## 提案している事業の骨子

> 事業名：「どんな壁も、乗り越えられる。」
> ソーシャルフットボールによる精神障がい当事者の健康づくり・社会参加促進事業

- **実施期間**：2027年4月1日 〜 2028年2月29日（募集要項の条件に合わせています）
- **柱1**：地域に開かれたオープン体験会・交流会（年5回・延べ100名以上）
- **柱2**：通年の練習環境の確保と競技力向上（定例練習40回／強化練習会12回／各大会出場）
- **柱3**：「はじめてのソーシャルフットボール ハンドブック」制作・配布と活動報告会
- **総事業費 1,360,000円／助成申請額 1,000,000円／自己資金 360,000円**

## 数字の根拠と、確認をお願いしたい点

- 費用の単価は**2026年9月時点の一般的な実勢価格に基づく見込み**です。実際の会場・
  業者の見積りに置き換えてください。
- 会員数・会費・参加者見込みは、公開情報から置いた**仮の値**です。
- 助成対象外とされる費目（例：団体の経常経費、飲食費など）があった場合は、
  当該費目を自己資金へ振り替え、助成申請額が1,000,000円を超えないよう調整してください。
  **費目の可否は、必ず財団の募集要項PDFまたは助成金事務局でご確認ください。**

## 募集の概要（2026年9月時点で確認できた範囲）

- 実施：公益財団法人ヤマト福祉財団　障がい者福祉助成金
- 助成上限：100万円
- 助成対象：①会議・講演会 ②ボランティア活動 ③**スポーツ活動・文化活動** ④調査・研究・出版
- 応募期間：2026年10月1日（木）〜 2026年11月30日（月）18時（電子申請システム Graain）
- 応募要件：2025年4月から1年以上の活動実績がある団体（個人不可）／過去2年間に
  当助成金を受けていないこと／**2027年4月以降に開始し2028年2月末日までに完了する事業**
- 選考委員会：2027年3月開催予定、結果はメールで通知
- 2027年度をもって本助成金は終了予定

> ※ 上記は検索結果から確認した内容です。作成環境から財団の公式ページ
> （https://www.yamato-fukushi.jp/works/subsidy.html ）に直接アクセスできなかったため、
> **応募前に必ず公式の募集要項PDFで原文をご確認ください。**

## ② 会則・総会議事録について

任意団体は、①に加えて **会則（規約）と直近の総会議事録** の提出が必要です。

## 資料の作り直し方

```bash
cd src

node build-kikakusho.js   # → 01_企画書.docx

```
