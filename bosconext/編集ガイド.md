# BOSCO NEXT サイト 編集ガイド

**ふだんの更新は、ほぼ全部「編集画面（/admin）」のフォームでできます。** HTMLやGitHubを触る必要はありません。

---

## A. 編集画面（/admin）でできること ★ほぼ全部こちら

編集画面 👉 **https://bosconext.netlify.app/bosconext/admin/**

（`https://weekendclub.github.io/bosconext/admin/` を開いても、自動でこちらに転送されます。どちらをブックマークしてもOKです）

開く → **「Login with GitHub」** → 左のメニューから項目を選ぶ → フォームを入力 → **「Publish（公開）」** → 1〜2分ほどでサイトに反映。

> ⚠️ **はじめて使うときは、一番下の「Z. 編集画面のログイン設定」を1回だけ行ってください。**
> これを済ませるまでは、ログインボタンを押しても入れません（画面自体は表示されます）。

編集できる項目（左メニュー）:
- **お知らせ** … 大会結果・活動報告・お知らせ。上にあるものほど新着表示。
- **トップの文章** … キャッチコピー、紹介文、成績バッジ、テロップ、メイン写真 など。
- **チーム・選手** … チーム紹介・チームデータ・選手（背番号/名前/写真）・スタッフ。
- **スケジュール** … これからの予定／これまでの結果。**予定の一番上が「次の一戦」**として大きく出ます（トップの「次の一戦」もここと連動）。
- **大会戦績** … 大会名と結果（優勝／準優勝／出場）。
- **フォトギャラリー** … 写真を**その場でアップロード**して追加。
- **リンク** … SNSや関連団体のリンク。

### 入力のコツ
- **写真**は、選手・ギャラリー・トップのメイン写真とも、フォームでアップロードできます。
- **キャッチコピー**は `{ }` で囲んだ言葉がゴールドで強調されます（例：`どんな壁も、{乗り越えられる}。`）。
- バッジやテロップ、紹介文の段落は「＋」で1行ずつ追加できます。
- 並べ替えはドラッグ。削除も各項目から。

### 編集する人を増やす
**DecapBridge** のダッシュボードで、編集者を**メール招待**します（招待された人はGitHubアカウント不要でログインできます）。

## B. デザインや一部のページを直すとき（GitHub）

次のものは、まだ編集画面に入れていないので、GitHubでファイルを編集します（ファイルを開く →鉛筆アイコン → 直す →「Commit changes」→ 自動公開）。

- **色・全体のデザイン** … `style.css`（上部の `:root` のカラーコード）
- **メニュー・SNSリンク・チーム名** … `site.js` の `SITE_INFO`
- **リーグ** … `league.html`／**新聞・雑誌切り抜き** … `press.html`／**会員専用** … `members.html`
- **お問い合わせフォームの通知先メール** … Netlifyの「Forms」設定（チームのGmール）

> これらも編集画面（フォーム）に追加できます。必要になったら教えてください。

## C. 仕組み（参考）

- 編集画面で入力した内容は、`〇〇.json`（news.json／home.json／team.json…）というデータファイルに保存され、各ページがそれを読み込んで表示します。
- パソコンでHTMLファイルを直接ひらいた“プレビュー”では、各ページに内蔵した予備データが表示されます（ネット上では .json が読まれるので問題ありません）。

## D. 困ったとき
- 反映されない → 1〜2分待つ／ブラウザを再読み込み。
- 間違えた・消した → GitHubの「履歴（Commits）」から元に戻せます。
- 直したい箇所を伝えてもらえれば、こちらで対応します。

## Z. 編集画面（/admin）のログイン設定 ★最初に1回だけ

編集画面は作成済みですが、**「誰がログインしてよいか」を決める設定だけ、GitHubとNetlifyの画面で1回行う必要があります**（どちらも無料。追加のアカウント登録は不要です）。

所要時間は5分ほどです。

### ステップ1：GitHubで「OAuthアプリ」を作る

1. GitHubにログインし、右上のアイコン → **Settings** を開く
2. 左メニューの一番下 **Developer settings** → **OAuth Apps** → **New OAuth App**
3. 次のとおり入力する：

   | 項目 | 入れる値 |
   |---|---|
   | Application name | `BOSCO NEXT CMS`（何でもOK） |
   | Homepage URL | `https://weekendclub.github.io/bosconext/` |
   | Authorization callback URL | `https://api.netlify.com/auth/done` |

4. **Register application** を押す
5. 表示された **Client ID** をコピーしておく
6. **Generate a new client secret** を押して、**Client Secret** もコピーしておく
   （シークレットは1度しか表示されません。閉じる前にコピーしてください）

### ステップ2：Netlifyに登録する

このサイトはすでにNetlifyと連携しています（`bosconext` プロジェクト）。

1. [Netlify](https://app.netlify.com/) を開き、**bosconext** のプロジェクトを選ぶ
2. **Site configuration**（または Site settings）→ **Access control** を開く
3. **OAuth** の欄で **Install provider** を押す
4. Provider に **GitHub** を選び、ステップ1の **Client ID** と **Client Secret** を貼り付けて保存

### ステップ3：ログインしてみる

**https://weekendclub.github.io/bosconext/admin/** を開いて、**「Login with GitHub」** を押します。
GitHubの確認画面が出たら許可 → 編集画面が開けば成功です🎉

> **編集できる人について**
> このリポジトリに書き込み権限があるGitHubアカウントなら誰でもログインできます。
> チームの他の人にも編集してもらいたい場合は、GitHubリポジトリの
> Settings → Collaborators から追加してください。

### うまくいかないときは

| 症状 | 確認すること |
|---|---|
| ログインで **「Not Found」** | ①`config.yml` の `site_domain` が Netlify のドメイン（`bosconext.netlify.app`）と一致しているか ②ステップ2のNetlify側の登録が完了しているか ③callback URL が `https://api.netlify.com/auth/done` か |
| ログインはできるが保存できない | そのGitHubアカウントにリポジトリの書き込み権限があるか |
| 画面が真っ暗のまま | 通信環境。時間をおいて再読み込み |

#### 「Not Found」が出るしくみ（参考）

ログインの窓口だけNetlifyを借りています。Netlifyは**アクセス元のドメインで「どのサイトの設定か」を判定**するため、
GitHub Pages（`weekendclub.github.io`）から開くと、そのままでは自分のサイトだと分かりません。
これを解決するのが `config.yml` の **`site_domain`** です。

さらに、Netlifyは**認証後のトークンを自分のドメイン宛てにしか返せない**ため、
GitHub Pages から開くと「GitHubで許可はできたのにログインが完了しない」状態になります。

そのため、**GitHub Pages のURLで開いた場合は、自動的にNetlify側のURLへ転送**するようにしてあります。
保存先は同じGitHubリポジトリなので、どちらから編集しても公開サイトに反映されます。

### 別の方法（DecapBridgeを使う場合）

Netlifyを使いたくない場合は、[DecapBridge](https://decapbridge.com/)（無料枠あり）でも同じことができます。
その場合は `bosconext/config.yml` の `backend:` を、ファイル内にコメントで書いてある
DecapBridge用の設定に差し替えて、`【あなたのサイトID】` を実際の値にしてください。
